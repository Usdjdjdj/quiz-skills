# Quiz Maker

A skill that tests knowledge of any topic. You name the topic and difficulty level, and the skill creates questions. It never explains the topic — it only asks.

## What it does

- Creates three question types: multiple choice, true/false, and open-ended.
- Orders questions from easy to hard.
- Collects all correct answers in a separate section at the end.
- Makes 5 questions by default.

## How to use

Give the skill a topic, for example:

- "Make a quiz about world capitals"
- "Test me on Python basics"
- "Quiz me on the solar system.
